Multipole Expansion
===================

The multipole module provides a fast far-field approximation for the vector
induction field generated by vortex particles. The core data structure and
operations are defined in ``src/core/multipole.h``.

The expansion approximates

.. math::

    \vec{v}(\vec{x}) = \sum_{i=1}^{n}
    \frac{\vec{\Gamma}_i}
    {|\vec{r}_i - \vec{x}|^2}

as a low-order series around a centre :math:`\mathbf{c}`:

.. math::

    \vec{v}(\vec{x}) \approx
    \sum_{m=0}^{p} \frac{1}{|\vec{x}-\mathbf{c}|^{2(m+1)}}
    \sum_{i=1}^{n} \vec{\Gamma}_i \,
    \bigl(2 (\vec{x}-\mathbf{c})\cdot(\vec{r}_i-\mathbf{c})
          - |\vec{r}_i-\mathbf{c}|^2\bigr)^{\!m}

The coefficients are organised as tetrahedral blocks per order, one
block per vector component (``x``, ``y``, ``z``).


Data Structure
--------------

.. c:type:: multipole_t

The main structure holding the expansion coefficients and metadata.

.. code-block:: c

    typedef struct {
        unsigned order;
        real3_t center;
        real_t *restrict coeffs_x;
        real_t *restrict coeffs_y;
        real_t *restrict coeffs_z;
    } multipole_t;

``order``
    Expansion order :math:`p \ge 0`.

``center``
    Centre :math:`\mathbf{c}` of the expansion.

``coeffs_x``, ``coeffs_y``, ``coeffs_z``
    Coefficient arrays for each vector component. Each has
    :c:func:`multipole_num_coeffs` elements, stored in tetrahedral
    block order.


Buffer Sizing
-------------

.. c:function:: size_t multipole_num_coeffs(unsigned order)

    Returns the number of coefficients needed per vector component
    for an expansion of given *order*. The total coefficient buffer
    must be :math:`3 \times` this value.

    :param order: Expansion order.
    :return: :math:`\binom{\text{order}+4}{4}`.

.. c:function:: size_t multipole_scratch_size(unsigned order)

    Returns the size of one scratch buffer (in ``real_t`` elements)
    needed by :c:func:`multipole_create` and :c:func:`multipole_update`.

    :param order: Expansion order.
    :return: :math:`(\text{order}+1)^3`.


Construction and Population
---------------------------

.. c:function:: bool multipole_create(unsigned order, unsigned num_coeffs, real_t *restrict coeffs, const real3_t center, unsigned sources, const real3_t *restrict sources_coords, const real3_t *restrict sources_values, real_t *restrict cur, real_t *restrict nxt, multipole_t *out)

    Build a multipole expansion from a set of source particles.

    The ``coeffs`` buffer must be at least :math:`3 \times`
    :c:func:`multipole_num_coeffs` elements long. The ``cur`` and
    ``nxt`` scratch buffers must each be at least
    :c:func:`multipole_scratch_size` elements long.

    :param order: Expansion order.
    :param num_coeffs: Size of the ``coeffs`` buffer (used for validation).
    :param coeffs: Flat coefficient array (will be written in-place).
    :param center: Centre of the expansion.
    :param sources: Number of source particles.
    :param sources_coords: Array of source positions.
    :param sources_values: Array of source vector strengths.
    :param cur: Scratch buffer (zeroed on entry).
    :param nxt: Scratch buffer (zeroed on entry).
    :param out: Output structure (pointers into ``coeffs``).
    :return: ``true`` on success, ``false`` on buffer-size mismatch.

.. c:function:: void multipole_update(const multipole_t *multipole, const real3_t center, const real3_t source_pos, const real3_t source_value, real_t *restrict cur, real_t *restrict nxt)

    Add a single source point to an existing multipole expansion.
    This is the incremental equivalent of :c:func:`multipole_create`.

    :param multipole: Expansion to update (coeffs are modified in-place).
    :param center: Centre of the expansion.
    :param source_pos: Position of the source to add.
    :param source_value: Vector strength of the source to add.
    :param cur: Scratch buffer (zeroed on entry).
    :param nxt: Scratch buffer (zeroed on entry).


Evaluation
----------

.. c:function:: real3_t multipole_eval(const multipole_t *multipole, const real3_t point)

    Evaluate the multipole expansion at a given point. The point is
    interpreted relative to the expansion's centre (i.e., the caller
    must subtract the centre before calling).

    The function is annotated with ``#pragma omp declare simd`` for
    vectorised evaluation over arrays of points.

    :param multipole: Expansion to evaluate.
    :param point: Point relative to the expansion centre.
    :return: Induced vector :math:`\vec{v}` at the point.


Shifting (Translation)
----------------------

.. c:function:: void multipole_add_shift(const multipole_t *in, const multipole_t *out, unsigned work_order, real_t *restrict shift_exp, real_t *restrict pse)

    Shift the expansion *in* and add its coefficients into *out*.
    This is the core operation for Barnes-Hut tree aggregation:
    child-node expansions are shifted to the parent node's centre
    and summed.

    The input and output orders need not be equal. The internal
    binomial series for the denominator :

    .. math::

        \frac{1}{|\vec{x} - \mathbf{c}_\text{in}|^{2}}

    is expanded to *work_order* (which must be :math:`\ge` both
    input and output orders), improving accuracy when the shift
    distance is large relative to the source cluster radius.

    The caller provides two work buffers:

    * ``shift_exp``: :math:`3 \times (\text{work\_order}+1)^2` elements.
    * ``pse``: :math:`2 \times \text{num\_coeffs}(\text{work\_order})` elements.

    Both are overwritten.

    :param in: Source expansion to shift.
    :param out: Target expansion (coefficients are modified in-place).
    :param work_order: Internal series order (:math:`\ge` both orders).
    :param shift_exp: Work buffer for binomial expansion of the shift.
    :param pse: Work buffer for polynomial series expansion.
