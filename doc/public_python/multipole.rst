Far-Field Approximation
=======================

The :class:`Multipole` type provides a fast far-field approximation for
the vector induction field generated by vortex particles. It replaces
exact summation over many source particles with a low-order
series expansion around a common centre, enabling the Barnes-Hut
algorithm for wake simulations.

A multipole expansion is constructed from source positions and vector
strengths, then evaluated at arbitrary target points. The expansion can
also be shifted (translated) to a new centre, which is the key operation
for tree-based aggregation.
